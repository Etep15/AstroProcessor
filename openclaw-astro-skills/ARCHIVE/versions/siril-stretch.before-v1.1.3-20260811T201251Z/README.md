# siril-stretch

This skill defines the iterative Stretch phase for the Siril SHO pipeline.

Installed files:
- `SKILL.md` — stage contract and operating rules
- `bin/stretch` — helper wrapper / usage entrypoint
- `scripts/ghs-pass.sh` — Siril GHS helper wrapper
- `scripts/black-point-pass.sh` — Siril BP shift helper wrapper
- `tests/TESTING.md` — manual installation and production test checklist
