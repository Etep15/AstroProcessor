# AstroProcessor

A script-driven astrophotography processing pipeline.

## Long-Term Goal
The project aims to build a comprehensive pipeline to automate the processing of astrophotography data, including:
- File ingestion and organization from remote sources (e.g., ASIAIR).
- FITS header analysis and sorting.
- Filter-specific processing and exposure evaluation.
- Stacking, alignment, and RGB combination.
- Star removal and final image processing.

Development will proceed incrementally, one clearly defined step at a time.
